# OC_Form

アウトリガーカヌーのフォーム解析システム。動画から骨格を推定し、将来的に Concept2 PM5 の実測データと同期して、フォームと出力の関係を解析する。

公開URL：https://chigasaki-outrigger-canoe-club.github.io/OC_Form/

## 使い方
1. 方向（前・左・右・後ろ）を選び、「動画を選択」で動画を読み込む（fpsは動画から自動取得）
2. 選手を選ぶ（「＋追加」で名前を付けて登録）。身長・体重・パドル寸法は選手ごとにブラウザ内へ自動保存。書き出し・読み込みでバックアップや別PCへの移動ができる
3. 「解析開始」で骨格推定 → ストロークの区切りと漕ぐ側が自動で入る
4. 停止中に関節をドラッグして修正、ストロークの区切り・漕ぐ側を表で修正
5. 3D骨格（推定）を回転・ズームして確認する。正面・側面・後方・上の固定視点あり
6. 「セッション」で練習日・メモを付けて保存する（動画も保存可）。一覧から過去のセッションを開ける
7. CSV・JSONで書き出す（バックアップや他のソフトでの分析用）

動画はブラウザ内でのみ処理し、外部に送信しない。初回のみMediaPipeのライブラリとモデルをCDNから取得する。

### 推奨ブラウザ
スマホで撮った動画（HEVC/H.265）は、**Chrome・Edge（Windows/Mac）またはSafari**で再生できる。ただしパソコンにHEVC対応（ハードウェア）がない場合は表示できない。その場合は画面に理由が表示されるので、カメラ設定をH.264にして撮影するか、H.264に変換する。

## 解析の考え方（推定値の扱い）
- **関節座標**：MediaPipeの推定値（`est`）。手動修正した点は `manual`。信頼度（visibility）0.5未満の点は薄く表示し、角度計算に使わない。
- **角度**：画像上の2D座標から計算した値。カメラの向きにより真の関節角度とは異なる。
- **ストロークの区切り**：低い方の手が最も高くなる時点（キャッチ直前付近）。キャッチの瞬間そのものではない。
- **3D骨格**：MediaPipeの worldLandmarks（腰の中心が原点、およそm）を、動画ごとに1つの回転で「X＝選手の左、Y＝上、Z＝選手の前」にそろえ、足の最も低い点の中央値を床とする。1台のカメラからの推定なので奥行きの精度は低い。
- **簡易パドル**：上の手がTグリップ（上端）を持ち、シャフトが両手を通ると仮定した推定値。ブレード面は前を向くと仮定。
- **漕ぐ側**：区切りと区切りの間で手が最も低い時点の「下の手」の側。ストロークごとに判定するため、パドルチェンジがあっても追従する。後方からの動画では左右の判定を誤ることがあるため確認が必要。

## データの保存場所
- 選手データ：ブラウザの localStorage
- セッション：ブラウザの IndexedDB（解析結果と動画は別に保存。動画1本で約60〜70MB）
- どちらもこのPCのこのブラウザ内だけ。ブラウザのデータを消去すると消える。別のブラウザやPCからは見えない
- 消える心配を減らすため、保存時にブラウザへ「自動で消さない」よう依頼している（許可されない場合もある）
- 削除：セッション一覧の「削除」。全部消す場合はブラウザの設定でこのサイトのデータを削除する

## 既知の制約
- 骨格推定は動画を1フレームずつ送って行うため、40秒の動画で数分かかる。
- MP4以外の動画はfpsを読めないため手入力が必要。
- 実寸換算（パドル長による校正）は未実装（MVP 2）。
- 3D表示は仕様書ではThree.jsだが、開発環境からライブラリを取得・検証できないため、現在は依存なしのCanvas描画で実装している。骨格と線の表示には十分で、面の表現や重ね合わせが必要になった段階でThree.jsへの移行を検討する。

## テスト
```
npm test
```
- 自動テスト36件：セッションの保存形式・要約・並び順、選手管理（追加・同名・更新・名前変更・削除・旧データ引き継ぎ・バックアップ）、3D座標の変換（カメラの向き5通り）、パドル推定、投影、圧縮形式の読み取り、時間・フレーム変換、角度、体幹の傾き、信頼度による除外、ストローク検出（一定ピッチ・パドルチェンジ・欠損あり）、MP4ヘッダ読み取り（30fps・25fps）、CSV・JSON出力
- 実動画のヘッダ読み取り：提供動画3本で fps・フレーム数がffprobeと一致（30fps/1167、30fps/1155、25fps/969）
- ブラウザ確認：模擬骨格データをJSON読み込みし、骨格表示・ドラッグ修正・ストローク表・グラフ・3Dビュー（固定視点・回転・ズーム）・CSV/JSON出力を確認。HEVC動画を表示できない環境でメッセージが出ることを確認。セッションの保存→ページを閉じて開き直し→開く・上書き・動画なしで開いて動画を選び直す・削除を確認
- **未確認**：実動画でのMediaPipe骨格推定とストローク検出の精度（開発環境からMediaPipeを取得できないため）
