# PM5（Concept2）をUSBで記録する

漕ぎながら、力の波形などをブラウザでリアルタイムに見て、すべてCSVに保存します。

## 準備（1回だけ）
1. Python 3 を入れる（https://www.python.org/downloads/ 。Windows はインストール時に「Add python.exe to PATH」にチェック）
2. このフォルダ（`tools/pm5`）をPCに置く（GitHubの「Code → Download ZIP」から取り出すなど）
3. このフォルダでコマンドプロンプト（ターミナル）を開き、次を実行
   ```
   pip install pywinusb
   ```
   （Mac・Linux は `pip install hidapi`）

## いちばん簡単な使い方（Windows）
- `demo.bat` をダブルクリック → PM5 なしで画面を試す（ブラウザが自動で開きます）
- `start.bat` をダブルクリック → PM5 の記録を始める（初回は通信用の部品 pywinusb を自動で入れます）

## コマンドで使う場合
1. PM5 の電源を入れ、USBケーブルでPCとつなぐ
2. このフォルダで実行
   ```
   python pm5_usb.py
   ```
3. ブラウザで http://localhost:8750 を開く → 漕ぐと波形が動きます
4. 終わったら Ctrl+C（PM5 の練習が終わったときも自動で止まります）

PM5 がなくても `python pm5_usb.py --demo` で画面を試せます。

## 保存されるファイル（このフォルダに、日時の名前で）
- `pm5_日時.csv`：1ストロークごとの記録（ワット・ピッチ・心拍・引きと戻しの時間・最大の力・力の立ち上がり・力の波形など）。
  フォーム解析サイトの「Concept2（エルゴ）」欄で読み込むと、グラフと改善点が出ます。
- `pm5_日時_raw.csv`：すべての測定値。力の波形を 64Hz（15.625ms ごと）で時間に沿って並べ、漕ぎの状態（2＝引き）つき。
  「キャッチから何秒で力を入れたか」を後から細かく解析するためのデータです。

## 用語
- 力の立ち上がり：キャッチ（PM5 が「引き」と判定した瞬間）から、力がその本の最大の10%を超えるまでの時間
- 最大までの時間：キャッチから、力が最大になるまでの時間
- 力の単位は lbs（PM5 の値のまま。1 lbs ≒ 4.45 N）

## うまく動かないとき
- 「PM5 が見つかりません」：ケーブル・電源を確認。ErgData など、ほかのアプリがPM5に接続していたら閉じる
- Mac/Linux で権限エラー：`sudo python pm5_usb.py` で試す
- 通信の命令の組み立ては Py3Row（BSD ライセンス、`LICENSE-Py3Row`）の `csafe_cmd.py`・`csafe_dic.py` を使っています
