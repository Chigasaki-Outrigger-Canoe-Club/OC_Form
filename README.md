# OC_Form

アウトリガーカヌーのフォーム解析サイト。動画（前・左・右・後ろ）から骨格を推定し、フォームの数値と改善点を出す。

公開URL：https://chigasaki-outrigger-canoe-club.github.io/OC_Form/

## 使い方
1. **選手**を選ぶ（「＋追加」で登録）。身長は cm の換算に使う
2. **動画と3Dモデル**：方向のタブごとに動画を選ぶ
3. メモを入れて「**実行**」：骨格推定 → 骨格の調整（4場面を手で合わせる）→ 3Dモデルと改善点 → 保存
   - 解析後に点を直したときは「**保存**」（解析し直さない）
4. **フォームの改善点**を見る（動画の2Dから測った数値）
5. **コメント**（一番上）：選んでいる選手のフォームへのコメントを、名前・本文・日時で積み上げる（掲示板ふう）
6. **選手比較**（ヘッダー）：保存したデータの動画と骨格を並べる。PC 4分割・スマホ 2分割、ストロークの同じ位置でそろえる

## 保存先
| もの | 場所 | 見られる人 |
|---|---|---|
| 解析結果・選手データ・動画 | このブラウザ（IndexedDB・localStorage）と Cloudflare R2（Worker 経由） | サイトを開ける人（見るのに合言葉は不要） |
| サイト本体 | GitHub（GitHub Pages） | 誰でも |

- 保存には合言葉（Worker の UPLOAD_KEY）が要る。保存のときに聞かれ、ブラウザごとに1回でよい
- 前に GitHub の `data` ブランチへ保存したデータは読むだけ。「保存の設定」の「GitHub の古いデータを Cloudflare へ移す」で移せる
- Worker の準備は `tools/r2-worker/README.md`

## 解析の考え方
- **フォームの数値は2Dから測る**（`js/form2d.js`）。横の動画はカメラ側を漕いだストロークで前傾・リーチ・肘など、前と後ろの動画で肩・骨盤・体幹の左右の傾きとシャフトの傾き。cm は胴の長さ＝身長の29%として換算した目安
- **3Dモデルは参考**（`js/fusion.js`）。同時撮影ではないので、ストロークを0〜100%にそろえ、関節ごとに得意な方向を使って合わせる。前と後ろの奥行きは使わない
- **ストロークの区切り**：手の高さで区切り、キャッチ（ドライブの始まり）へ移す。後ろの動画は肩の傾きで区切る（`js/tilt.js`）
- 推定の確かさは、人が付けた正解フレームとのずれで判断する（信頼度や平滑化だけで良くなったとは言わない）

## ファイル構成（主なもの）
| ファイル | 役割 |
|---|---|
| `index.html`・`compare.html` | 解析ページ・選手比較ページ |
| `js/main.js` | 解析ページの操作 |
| `js/pose.js`・`hands.js`・`shaft.js` | 骨格・手・シャフトの推定 |
| `js/strokes.js`・`drive.js`・`tilt.js` | ストロークの区切り |
| `js/form2d.js`・`feedback.js` | フォームの数値と改善点（目安は `LIMITS`） |
| `js/fusion.js`・`body3d.js`・`view3d.js` | 3Dモデル |
| `js/compare.js` | 選手比較 |
| `js/comments.js` | コメント（掲示板） |
| `js/sessions.js`・`github.js`・`r2.js` | 保存 |
| `tools/r2-worker/` | Cloudflare Worker（R2 への保存と読み出し。GitHub と連携して自動で作り直される） |
| `tools/pm5/` | Concept2 PM5 を USB で記録するツール |
| `docs/requirements.md` | 要件・決定事項・会話の記録 |
