# OC_Form

アウトリガーカヌーのフォーム解析システム。動画から骨格を推定し、将来的に Concept2 PM5 の実測データと同期して、フォームと出力の関係を解析する。

公開URL：https://chigasaki-outrigger-canoe-club.github.io/OC_Form/

## 使い方
1. 方向（前・左・右・後ろ）を選ぶ
2. 「動画を選択」で動画ファイルを読み込む（方向ごとに1本）
3. 再生・停止・シーク・コマ送り・速度変更で確認する

動画はブラウザ内でのみ処理し、外部に送信しない。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目（色・余白は `:root` で一括定義） |
| `js/main.js` | 画面の操作（読み込み・方向切り替え・再生操作） |
| `js/frame-math.js` | 時間とフレーム番号の計算（表示処理から分離） |
| `tests/` | 自動テスト（`npm test`） |

## 既知の制約
- ブラウザは動画の正確なフレーム番号やfpsを提供しない。フレーム番号は手入力したfps（初期値60）からの**推定値**。
- 再生できる動画形式はブラウザに依存する（スマホ撮影のHEVC/H.265はブラウザによって再生できない場合がある）。
